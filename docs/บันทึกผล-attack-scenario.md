# บันทึกผลการทดสอบ Attack Scenario
สรุปสั้น ๆ ว่าทดสอบ payload ขนาดใหญ่ (ขั้นตอนที่ 3.4) และ type confusion (ขั้นตอนที่ 3.5) ได้ผลอย่างไร พร้อมข้อสังเกตของตนเอง

## ทดสอบ payload ขนาดใหญ่ (ขั้นตอนที่ 3.4) 

- จากการทดสอบ Payload ขนาดใหญ่ โดยส่งข้อมูลที่มีขนาดเกิน 10KB ไปยัง `POST /api/v1/students `พบว่าระบบสามารถป้องกันคำขอที่มีขนาดใหญ่ผิดปกติได้ โดยตอบกลับด้วย Status Code `413 Payload Too Large `
- แสดงว่าการกำหนด `express.json({ limit: "10kb" }) `สามารถทำงานได้ตามที่คาด

## type confusion (ขั้นตอนที่ 3.5)

- จากการทดสอบ Type Confusion พบว่าระบบยังสามารถรับค่า `name` ที่เป็น Object แทน String ได้ 
- เนื่องจากการตรวจสอบข้อมูลในปัจจุบันตรวจเพียงว่ามีค่า `name` หรือไม่ แต่ยังไม่ได้ตรวจสอบชนิดข้อมูล  คิดว่าควรตรวจสอบชนิดและรูปแบบของข้อมูลก่อนนำไปใช้งาน เช่น ตรวจว่า name ต้องเป็น String และมีความยาวตามที่กำหนด
